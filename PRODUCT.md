# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

React 18 + Vite, framer-motion, lucide-react, axios

## Users

Primary: Bhavishya (personal user). Secondary: demo/showcase audience.

## Product Purpose

JARVIS 2.0 web interface — a chat-style AI companion frontend powered by the Gemini backend with the Kyuoko Hori persona (from Horimiya). The interface allows the user to type commands and receive responses from the AI assistant, with a sci-fi anime-inspired dark aesthetic.

## Positioning

A personal AI assistant web UI with a distinctive anime-inspired character persona (Kyuoko Hori), dark sci-fi aesthetic, and real-time chat interaction with tool-calling capabilities visible in the interface.

## Operating Context

Demo and personal use. The interface showcases the JARVIS 2.0 backend capabilities (tool calling, memory, wake word) through a polished web UI.

## Constraints

- Dark mode only (anime-inspired sci-fi palette)
- React 18 + Vite stack
- framer-motion for animations
- lucide-react for icons
- axios for API calls
